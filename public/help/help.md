#### Sequence Tube Map

Visualize pangenome sequence graphs in a tube-map style.

---

**Opening data**

Use **File → Sample data** to browse built-in datasets, or **File → Open custom files** to upload your own graph, read, or haplotype files. Add and configure tracks with the **Track Picker** button.

---

**Region format**

| Format | Example |
|---|---|
| Coordinate range | `chr1:1000-2000` |
| Start + length | `chr1:1000+500` |
| Node ID range | `node:42-55` |
| Node + length | `node:42+10` |

---

**BED file**

Select a BED file to jump between pre-extracted regions using the **Prev / Next** buttons.

---

**Simplify**

Removes small snarls (SNPs, single-base indels). Only available when there are no read tracks.
